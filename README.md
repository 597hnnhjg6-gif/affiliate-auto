この公開リポジトリは、静的なサイト成果物 `docs/` と GitHub Pages デプロイ用ワークフローだけを管理します。

- `docs/`: 公開用 HTML、robots.txt、sitemap.xml、検索エンジン所有権確認ファイル
- `.github/workflows/publish.yml`: `docs/` 更新時の GitHub Pages デプロイ
- 開発用 Python、承認広告の元データ、検証処理、運用手順は Private リポジトリで管理します
- 広告掲載状況や報酬は保証しません。掲載条件やPR表示は公開前に確認します

**注意:** Git の過去コミットに含まれていたファイルは、現在のツリーから削除しても履歴には残ります。
