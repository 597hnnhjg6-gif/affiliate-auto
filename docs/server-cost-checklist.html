サービス比較ノート

レンタルサーバーの料金比較で見落としやすい費用

広告に表示される月額料金は、契約期間やキャンペーンの適用条件によって実際の支払額と異なることがあります。

比較するときの項目

  • 初回契約の合計金額
  • 更新時の月額換算額
  • 独自ドメインの取得・更新費
  • バックアップや復元の追加費用
  • 契約期間と途中解約時の条件
  • 支払方法と税の扱い

計算例

初回12か月分が合計6,000円なら月額換算は500円です。ただし更新料金が異なる場合、2年目以降は別に計算する必要があります。これは説明用の仮定であり、特定サービスの料金ではありません。
