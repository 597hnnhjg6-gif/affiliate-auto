WordPressブログを始める前の準備

WordPressでブログを作るには、公開場所となるサーバー、必要に応じて独自ドメイン、記事を管理する仕組みを用意します。

準備チェックリスト

  1. ブログのテーマと想定読者を決める
  2. 独自ドメインを使うか決める
  3. WordPressに対応するサーバーを選ぶ
  4. SSL（HTTPS）を有効にする
  5. 管理者のパスワードと二要素認証を設定する
  6. バックアップと更新の運用を決める
  7. プライバシーポリシーや広告表示の要否を確認する

公開後の運用

テーマやプラグインを定期更新し、バックアップを確認しましょう。広告を掲載する場合は利用するASPと広告主の条件も確認してください。

関連：レンタルサーバーの選び方

広告を含む場合があります。情報は掲載時点のものです。最新の条件は公式サイトをご確認ください。
