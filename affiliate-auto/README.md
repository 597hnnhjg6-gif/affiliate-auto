# 無料アフィリエイト自動公開サイト

## 最初に
1. GitHubで公開リポジトリを作成し、このフォルダの中身を `main` ブランチへアップロード。
2. リポジトリの Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定。
3. `data/offers.csv` に、ASPで提携承認済みの案件と正確な説明、広告リンクを登録。`id` は半角小文字・数字・ハイフンのみ。
4. `enabled` を `true` に変更してコミットすると自動公開。Actions → Build and deploy → Run workflow から手動実行も可能。
5. 公開URLは通常 `https://ユーザー名.github.io/リポジトリ名/`。初回反映まで時間がかかる場合あり。

## 運用と注意
- 毎日10:17 UTCに再生成（日本時間19:17）。GitHubのスケジュール実行は遅延・停止する場合があります。
- 料金・広告条件の自動取得はしません。`verified_at` と内容を定期的に見直してください。
- 記事はテンプレートベース。AI生成・検索上位表示・自動収益を保証するものではありません。
- 公開前に運営者情報、連絡先、プライバシーポリシー、ASP指定の広告表記を整備してください。
- アフィリエイトURLは提携先の掲載規約を確認し、許可された形式で入力してください。
- 無料枠や規約は変わる可能性があります。公開リポジトリには秘密情報を入れないでください。

## ローカル実行
`python scripts/build.py` を実行し、`docs/index.html` をブラウザで開きます。

## 公開前チェック（追加）
- `python scripts/check.py` で、必須項目、重複ID、HTTPSリンク、情報確認日を検査します。
- 公開対象の案件に不備があればGitHub Actionsは公開を停止します。確認日から90日を超えた案件は警告します（公開停止はしません）。
- PR表記があっても、ASP・媒体ごとの掲載規約と日本の広告表示ルールを別途確認してください。
- 収益やクリック数の自動取得、AIによる新規記事の自動作成、ASP案件の自動取得は未実装です。

## v3: 無料の集客用ツール
- `docs/cloud-cost-calculator.html` を自動生成。2サービスの月額・期間総額をブラウザ内で計算できます。
- サイトのトップページからツールにリンクします。広告未承認でも有用な無料コンテンツを公開できます。
- これは集客用の土台であり、アクセスや収益を生み出す保証はありません。
- 実際の入金にはASP登録・審査・広告掲載・成約が必要です。GitHubアカウントへのログインや公開操作は実施していません。

## v4: 2役の自動改善サイクル（API費用0円）
- `python scripts/agents.py`: 企画役が未公開ツールを1件選択、審査役が入力とテンプレートをチェックしてからHTMLを生成します。
- これは**ルールベースの2役シミュレーション**であり、独立したAIモデル同士の対話ではありません。外部AI API・課金は使用しません。
- `data/agent_state.json` に公開済みIDを記録します。GitHub Actionsはファイル変更をリポジトリに自動コミットしません。今回は3件すべてを生成した状態を同梱し、毎回再生成します。新規企画を継続追加するには候補の追加と状態管理が必要です。
- 企画候補はコード内の3件のみ。候補がなくなれば追加生成は停止します。
- 広告リンクの自動取得、外部サイトへの投稿、口座開設、収益発生は実装していません。

## v5: 無料公開前の自動テスト
- `python scripts/test_site.py` でデータ検証、2役の生成、サイト生成、内部リンク、PR表記を一括確認します。
- GitHub Actionsも同じテストを実行し、失敗時は公開しません。追加APIや有料サービスは使いません。
- GitHubへのアップロード、Pages設定、ASP提携は未実施です。実収益は発生していません。
- **重要:** この仕組みはGitHub上に置いて初めて定期実行されます。公開前に運営者情報・問い合わせ先・プライバシーポリシーを整備してください。
